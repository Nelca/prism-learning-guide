# 自然関連の環境価値を読む

GHG算定の実務経験者に向けて、自然関連の環境価値評価とPRISMの計算・判断・開示を解説する図解教材です。

- [Web版](https://nelca.github.io/prism-learning-guide/)
- [PDF版（39ページ）](https://nelca.github.io/prism-learning-guide/prism-learning-guide.pdf)
- 図解改訂版 v3.0：2026年9月22日
- 本文12章、図14点、表21点、付録4編

## 構成

1. 評価の基礎：GHG算定との対応、価値概念、節水の計算例、評価設計、枠組みと手法
2. PRISMを読む：入力・出力、内部計算、不確実性、手法間差、財務・NPV、開示・台帳
3. 実務で使う：専門家との対話、判断メモ、解答付き演習
4. 付録：通しの計算例、発展事項、用語、原典と実装の確認先

## 更新・公開

GitHub Pagesの公開元は `main` ブランチの `/docs` です。Web版は `docs/index.html` にCSS・SVG・JavaScriptを含む自己完結型HTMLです。Web表示には外部ライブラリやビルド処理は不要です。

本文を更新する場合は、PDF版も同じ内容で再出力してください。PDFには補足と解答をすべて収録し、印刷目次のページ番号を付けています。改ページ後は目次と実ページの対応も確認してください。

リポジトリとGitHub Pagesはともに公開です。公開対象は学習資料と公開用の設定ファイルで、PRISM本体のソースコード・係数ファイル・ローカルのレビュー記録は含みません。本文中の実装パスは根拠を示す参照名です。
